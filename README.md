# Space Portfolio

Ankush Kumar Sharma's space-themed portfolio website showcasing web design, interactive UX, and data analytics experience.

## Overview

This project is a personal portfolio built with HTML, CSS, and JavaScript. It includes a space-inspired layout, animated starfield backgrounds, interactive navigation, and content sections for skills, projects, education, and contact details.

## Key Features

- Space-themed landing page with animated graphics and glow effects
- Interactive navigation and responsive layout for desktop and mobile
- Portfolio sections for skills, education, training, and achievements
- Ready for deployment on GitHub Pages, Netlify, or Vercel

## Files

- `index.html` — main entry page for the portfolio
- `portfolio.html` — additional portfolio or project page content
- `styles.css` — global styling and visual effects
- `script.js` — interactive behavior and animations
- `README.md` — project overview and deployment notes
- `netlify.toml` — Netlify deployment configuration
- `vercel.json` — Vercel deployment configuration
- `.github/workflows/deploy.yml` — GitHub Actions workflow for GitHub Pages

## Deployment

This repository is configured to deploy with GitHub Actions using GitHub Pages. The workflow file is located at `.github/workflows/deploy.yml`.

To deploy manually:

1. Push the `main` branch to GitHub.
2. Enable GitHub Pages in the repository settings.
3. Select the `gh-pages` branch or the workflow deployment option if configured.

## Notes

- The site is designed to work as a static portfolio page.
- If GitHub Pages deployment fails, verify the repository settings and GitHub Actions permissions.
