# Portfolio Website

This repository contains a static portfolio website for Ankush Kumar Sharma.

## Files included

- `index.html` — The main website entry point for GitHub Pages.
- `portfolio.html` — The original portfolio page source.

## Deployment

This site is ready to be served via GitHub Pages from the repository root.

### GitHub Pages setup

1. Open the repository on GitHub: https://github.com/Ankush-kr-Sharma/potfolio
2. Go to `Settings` → `Pages`.
3. Choose branch `master` and folder `/ (root)`.
4. Save.

### Local preview

Open `index.html` in your browser to preview the site locally.

## Notes

- `index.html` is a duplicate of `portfolio.html` so the site can be served correctly from the project root.
- No additional build or tools are required.
