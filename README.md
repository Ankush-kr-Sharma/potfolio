# Portfolio Website

A static GitHub Pages portfolio for **Ankush Kumar Sharma**.

## Overview

This repository hosts a space-themed data analytics portfolio website built as a single-page HTML experience. It includes animated canvas effects, responsive layout, and modern cyber/space styling.

## Repository contents

- `index.html` — Main entry point for GitHub Pages.
- `portfolio.html` — Original portfolio page source file.
- `README.md` — Project and deployment documentation.

## Features

- Animated starfield and cosmic background using HTML Canvas.
- Responsive navigation and sections for skills, experience, projects, and contact.
- Google Fonts integration for a futuristic visual style.
- No build tools required: deploy directly as a static HTML site.

## Deployment

This repository is ready for GitHub Pages deployment from the root.

### GitHub Pages setup

1. Open the repository on GitHub: `https://github.com/Ankush-kr-Sharma/potfolio`
2. Go to `Settings` → `Pages`.
3. Set the source to branch `master` and folder `/ (root)`.
4. Save.
5. GitHub will publish the site shortly.

### Expected published URL

- `https://ankush-kr-sharma.github.io/potfolio/`

> If Pages is not yet enabled, wait a few minutes after enabling and refresh the Pages settings page.

## Local preview

1. Open `index.html` locally in a web browser.
2. No server or build step is required.

## Notes

- The site is static and does not require backend services.
- `index.html` and `portfolio.html` are identical to ensure the site works both locally and on GitHub Pages.
